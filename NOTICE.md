# Notices

NASAQ is a layer on top of [Omarchy](https://github.com/omacom/omarchy) (MIT). Several plugins
started as copies of Omarchy's own shell plugins (`omarchy plugin clone`) and keep its structure:
`nasaq.bar` (from `omarchy.bar`), `nasaq.lock` (`omarchy.lock`), `nasaq.notifications`
(`omarchy.notifications`), `nasaq.tray`, `nasaq.workspaces`, `nasaq.audio`, `nasaq.monitor`,
`nasaq.keyboard-layout`. Copyright for those parts remains with the Omarchy authors under the MIT licence.

Built on [Quickshell](https://quickshell.org) (LGPL-3.0). Ideas were studied from DankMaterialShell,
Noctalia, Caelestia, illogical-impulse, Ambxst, Wayle, VGS and others; no code was copied from
GPL or AGPL projects.

Optional tools used when present: matugen, tesseract, cava, nwg-displays, tensaku, Claude Code.
